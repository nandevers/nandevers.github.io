01 / THE PROBLEM

One business. Many views of demand.

Teams forecast at different levels for different decisions. If each series is modeled independently, the global forecast may not equal the sum of its components. That gap creates avoidable disagreement in planning, capacity and inventory conversations.

03 / RECONCILIATION CHOICES

Coherence is a constraint. Accuracy is a test.

Bottom-up sums bottom-level forecasts. Top-down allocates an aggregate forecast using proportions. MinT methods choose coherent values using forecast-error covariance assumptions. Each approach has tradeoffs; compare them out of sample at the levels and horizons where decisions are made.

BOTTOM-UP

Preserve the leaves

Keep the bottom-level forecasts, then sum upward. Straightforward and coherent; aggregate-level information from separate forecasts is not used.

TOP-DOWN

Allocate from the top

Forecast the aggregate, then distribute it down the hierarchy. The shares matter and can obscure bottom-level patterns.

MINT / MINTRACE

Use error structure

Project base forecasts onto the coherent space while accounting for forecast-error covariance. Estimating that structure well is part of the modeling work.

from neuralforecast import NeuralForecast
from neuralforecast.models import NHITS, HINT
from neuralforecast.losses.pytorch import GMM, sCRPS
from hierarchicalforecast.core import HierarchicalReconciliation
from hierarchicalforecast.methods import BottomUp, MinTrace

# HINT combines a neural base model with hierarchy-aware reconciliation.
quantiles = np.array([0.1, 0.5, 0.9])
base = NHITS(
    h=horizon,
    input_size=24,
    loss=GMM(n_components=10, quantiles=quantiles),
    valid_loss=sCRPS(quantiles=quantiles),
    max_steps=2000,
)
hint = HINT(
    h=horizon,
    S=S_df.drop(columns="unique_id").to_numpy(),
    model=base,
    reconciliation="BottomUp",

nf = NeuralForecast(models=[hint], freq="MS")
nf.fit(df=train_df, val_size=horizon)
