Where this work comes from

During my master’s in Digital Agriculture, I studied reinforcement learning for crop-insurance fraud prevention. The gym-insurance repository documents that research direction, connecting economic constraints with sequential decision-making.

Academic research, with subsequent repository experiments. The code is not a validated fraud-detection product.

The research question

How should a policy make a sequence of insurance decisions when each choice changes the remaining budget?

The thesis brought together my interests in economics, machine learning and decision-making. The public gym-insurance repository contains InsurEnv, an experimental environment for studying insurance-claim decisions with reinforcement learning.

Thesis title
Reinforcement Learning Applied to Fraud Prevention for Crop Insurance

Inside the research

From data to a decision policy.

  1. Prepare the insurance data

    The repository includes data-preparation scripts and a sample selection for soybean insurance in Paraná, Brazil.

  2. Represent the decision environment

    InsurEnv combines claim features, budget usage, approval history and statistical signals in a Gym-style environment with two actions.

  3. Define the learning signal

    The environment's reward compares Benford-distance measures for selected claim values. A wallet component tracks decisions and the available budget.

  4. Study a learned policy

    The public code includes a TensorFlow/Keras Deep Q-Network agent with experience replay, a target network and exploration, alongside scripts for random-agent comparisons and experiment analysis.

What the signal means

Benford conformity is a statistical proxy. Confirmed fraud labels are needed to measure fraud-detection performance. Reward improvement alone does not establish that fraudulent claims have been identified.
